### Linear Regression From Scratch

An educational implementation of linear regression using Python and NumPy, with visualizations created using Matplotlib.

## Objectives
Understand the mathematics behind linear regression.

Implement the Mean Squared Error cost function.

Implement gradient descent from scratch.

Visualize the optimization process.

Experiment with different learning rates.
## Technologies
Python

NumPy

Matplotlib

Jupyter Notebook
## Project Status

Currently under development.

## Installation

Clone the repository and install the dependencies:

    pip install -r requirements.txt


Open the notebook:

    jupyter notebook


Navigate to notebooks/linear_regression.ipynb to explore the implementation.
